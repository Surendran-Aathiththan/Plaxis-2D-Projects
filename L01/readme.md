 # Plaxis 2d L01

- Axisymmetric Model: A 2D setup used to simulate 3D circular structures (like driven piles, shafts, or circular footings).
- Plain strain: Assumes the structure and soil profile are infinitely long (Retaining walls, embankments, long tunnels, and strip footings)

- 15-Node Element: A highly accurate triangular mesh shape. Each triangle has 15 calculation points (nodes).
